# 홈택스 전자세금계산서 자동 발행

홈택스 화면을 코드가 사람처럼 조작해 전자세금계산서를 발행합니다. 로그인부터 서명까지 끝까지 자동으로 돌아가고, 사람은 누구에게 얼마를 발행할지만 정하면 됩니다.

발급 대행 서비스를 쓰지 않습니다. 건당 비용이 없고, 내 PC에서만 돕니다. 아이디와 비밀번호, 보안카드는 내 컴퓨터 밖으로 나가지 않습니다.

2026년 9월 기준 홈택스 화면에서 실제 발행과 취소까지 확인했습니다.

## 무엇이 되나

- 아이디 로그인과 그다음 주민번호 2차 인증까지 자동
- 공급받는자, 작성일자, 품목, 금액 채우기 자동
- 보안카드 서명 자동. 홈택스가 매번 다르게 묻는 번호를 저장해 둔 카드에서 찾아 넣습니다
- 발행 결과의 승인번호를 읽어 기록
- 이미 발행한 계산서를 전액 취소(수정발급)

## 준비물

1. **전자세금계산서 발급용 보안카드.** 가까운 세무서에서 무료로 받습니다. 개인사업자는 대표자 신분증만 있으면 되고, 법인은 3개월 안에 뗀 법인 인감증명서를 함께 가져갑니다. 온라인 신청은 없습니다. 신청한 날 바로는 못 쓰고 다음날 오후부터 열립니다. 그래서 이것부터 해야 합니다.
2. **홈택스 아이디와 비밀번호.**
3. **윈도우 PC 또는 맥과 크롬.** 창을 띄운 채로 돌기 때문에 화면이 켜져 있어야 합니다.
4. **파이썬 3.10 이상.**

## 설치

윈도우는 PowerShell, 맥은 터미널을 엽니다.

```bash
git clone https://github.com/wnstjd878/hometax-auto.git
cd hometax-auto
pip install playwright
playwright install chromium
```

맥에서 `pip` 나 `python` 을 못 찾는다면 `pip3`, `python3` 으로 바꿔 치면 됩니다. 아래 예시는 전부 `python` 으로 적었습니다.

보안카드를 사진으로 읽고 싶으면 이것도 설치합니다. 인터넷을 쓰지 않고 윈도우에 들어 있는 글자 인식을 부르며, **이 기능은 윈도우에서만 됩니다.** 맥에서는 카드를 직접 입력합니다.

```bash
pip install winocr winrt-runtime winrt-Windows.Media.Ocr winrt-Windows.Globalization winrt-Windows.Storage.Streams winrt-Windows.Graphics.Imaging winrt-Windows.Foundation
```

## 쓰는 순서

**1. 자격을 저장합니다.** 본인 명령창에서 직접 실행하세요. 비밀번호와 주민번호는 화면에 안 보입니다.

```bash
python setup_creds.py login
```

홈택스 아이디, 비밀번호, 주민등록번호 앞 여섯 개와 뒷자리 첫 숫자 하나를 묻습니다. 홈택스는 아이디로 로그인하면 이 일곱 개를 2차 인증으로 한 번 더 묻습니다.

**2. 보안카드를 저장합니다.**

```bash
python setup_creds.py card
```

일련번호를 먼저 묻고, 그다음 1번부터 차례대로 네 개짜리 숫자를 받습니다. 프롬프트가 지금 몇 번을 기다리는지 보여줍니다. 한 줄에 여러 개를 붙여 넣어도 되고, 고칠 때만 `7 1234` 처럼 번호를 앞에 붙입니다.

카드 사진으로 넣고 싶으면 이렇게 합니다. 사진은 이 PC 밖으로 나가지 않습니다.

```powershell
python read_card.py "C:\경로\카드사진.jpg"
```

맥에서는 이 명령이 막히고 직접 입력하라는 안내가 나옵니다.

읽은 숫자를 번호별로 보여주니 실물과 대조하고 저장하세요. 카드에 따라 왼쪽 번호가 인식되지 않을 수 있는데, 그때는 직접 넣는 편이 빠릅니다.

**3. 저장 상태를 확인합니다.** 내용은 안 보여주고 들어갔는지만 알려줍니다.

```bash
python setup_creds.py status
```

**4. 크롬을 띄웁니다.** 이 도구 전용 크롬이고 평소 쓰는 크롬과 분리됩니다.

윈도우 PowerShell

```powershell
powershell -ExecutionPolicy Bypass -File launch_chrome.ps1
```

맥 터미널

```bash
chmod +x launch_chrome.sh
./launch_chrome.sh
```

둘 다 조종 포트 9260 에 전용 크롬을 띄웁니다. 이미 떠 있으면 그대로 씁니다.

**5. 발행할 내용을 적습니다.** `invoices.sample.json` 을 복사해 `invoices.json` 으로 만들고 고칩니다.

**6. 먼저 채우기만 해봅니다. 발급은 안 합니다.**

```bash
python issue.py fill invoices.json --index 0 --preview
```

크롬 창에서 홈택스에 로그인이 안 돼 있으면 먼저 로그인합니다.

```bash
python login.py
```

**7. 화면이 맞으면 발행합니다.**

```bash
python issue.py fill invoices.json --index 0 --issue --card
```

`--card` 를 빼면 인증서 창을 띄우고 비밀번호는 사람이 칩니다.

여러 건이면 한 번에 돌립니다. 목록에 적은 순서대로 발행하고, 한 건이라도 막히면 거기서 멈춥니다.

```bash
python issue.py all invoices.json --card
```

## 매번 치기 귀찮으면 더블클릭 하나로 씁니다

위 4번부터 7번까지를 파일 하나에 적어 두었습니다. 윈도우는 `run.bat`, 맥은 `run.command` 를 더블클릭하면 크롬을 띄우고 로그인한 다음 `invoices.json` 에 적어 둔 것을 전부 발행합니다. 한 단계라도 막히면 거기서 멈추고 마지막 줄에 이유를 남깁니다.

맥은 처음 한 번만 실행 권한을 줍니다.

```bash
chmod +x run.command
```

`invoices.json` 이 없으면 아무것도 하지 않고 그 사실만 알려줍니다. 발행할 내용을 먼저 적어 두세요.

## 정해진 시각에 알아서 돌게 하려면 (정기 계산서만)

세금계산서는 거래가 생길 때마다 한 건씩 발행하는 것이 기본이고, 그때는 위 텔레그램이나 명령으로 그 자리에서 발행합니다. 매달 같은 거래처에 같은 금액이 나가는 정기 계산서에 한해 예약을 걸어 둘 수 있습니다. 윈도우는 PowerShell 에서 아래 한 줄이면 매달 25일 오전 9시에 위 파일이 실행됩니다. 경로는 내려받은 폴더로 바꿔 주세요.

```powershell
schtasks /create /tn "세금계산서 발행" /tr "C:\hometax-auto\run.bat" /sc monthly /d 25 /st 09:00
```

맥은 터미널에서 `crontab -e` 를 치고 아래 한 줄을 넣습니다.

```bash
0 9 25 * * cd ~/hometax-auto && ./run.command >> logs/cron.log 2>&1
```

두 가지를 주의하세요. 크롬 창을 띄워 홈택스를 조작하기 때문에 그 시각에 컴퓨터가 켜져 있어야 하고, 보안카드 인증이 거절되면 `logs/card_fail.lock` 이 남아 사람이 지울 때까지 다음 예약도 멈춥니다.

## 폰에서 시키고 싶으면 텔레그램을 붙입니다 (안 해도 됩니다)

여기까지만 해도 발행은 전부 됩니다. 아래는 폰에서 발행을 시키고 결과를 받고 싶을 때만 하는 선택 사항이니 필요 없으면 건너뛰세요.

**1. 봇을 하나 만듭니다.** 텔레그램에서 `@BotFather` 를 찾아 `/newbot` 을 보내고 이름을 정하면 열쇠를 하나 줍니다.

**2. 그 봇과 대화를 시작하고 아무 말이나 한 번 보냅니다.** 이렇게 해야 봇이 내 대화방 번호를 알 수 있습니다.

**3. 열쇠를 저장합니다.** 대화방 번호는 열쇠만 넣으면 알아서 찾아옵니다.

```bash
pip install python-telegram-bot
python setup_creds.py telegram
```

**4. 봇을 띄워 둡니다.** 이 창을 닫으면 봇도 같이 멈추니 발행이 끝날 때까지 열어 두세요.

```bash
python telegram_bot.py
```

**5. 거래처에서 사업자등록증이 오면 그 자리에서 폰으로 보냅니다.** 건마다 이렇게 발행하고, 손으로 칠 것은 금액뿐입니다.

1. 거래처에서 받은 사업자등록증 사진이나 PDF 를 봇에게 보냅니다. 상호와 등록번호와 대표자를 읽어 되돌려 줍니다.
2. 처음 보는 거래처면 계산서 받을 이메일을 한 번 묻습니다. 답장하면 `~/.hometax/partners.json` 에 적어 두고 다음부터는 안 묻습니다.
3. 공급가액을 답장합니다. `150만`, `1,500,000`, `165만 포함` 처럼 쓰면 되고, 포함을 붙이면 부가세가 들어간 금액으로 보고 공급가액과 세액으로 나눕니다. `150만 광고대행 수수료` 처럼 품목을 같이 써도 됩니다.
4. `발행해줘` 라고 보냅니다. 이 PC 에서 크롬이 떠서 홈택스를 조작하고, 끝나면 승인번호가 폰으로 돌아옵니다.

사진을 읽는 순서는 이렇습니다. 이 PC 에 `claude` 명령이 설치돼 있으면 그것으로 읽고(PDF 도 읽습니다), 없으면 윈도우에 들어 있는 글자 인식으로 읽습니다. 어느 쪽이든 사진은 이 컴퓨터 밖으로 나가지 않습니다. 읽은 내용이 틀렸으면 아래 글자 명령으로 넣으세요.

읽기만 따로 확인하려면 이렇게 합니다.

```bash
python bizreg.py 사업자등록증.jpg
```

사진 없이 글자로도 넣을 수 있습니다.

| 보내는 말 | 하는 일 |
|---|---|
| `목록` | 발행 대기 중인 건을 보여줍니다 |
| `추가 예시상사,000-00-00000,홍길동,a@b.com,150만` | 한 건 넣습니다 |
| `발행해줘` | 목록을 전부 발행하고 승인번호를 보내줍니다 |
| `취소 20260101-10260101-12345678` | 그 계산서를 전액 취소합니다 |
| `비우기` | 목록과 읽어 둔 사진 건을 지웁니다 |

발행이 도는 동안 이 PC 화면에 크롬이 떠서 홈택스를 조작하므로 컴퓨터는 켜져 있어야 합니다.

**8. 잘못 발행했으면 취소합니다.**

```bash
python cancel.py 20260101-10260101-12345678
```

사유는 "착오에 의한 이중발급 등" 으로 전액 취소 한 장이 자동으로 만들어집니다.

## 반드시 알아야 할 것

**보안카드는 다섯 번 틀리면 정지됩니다.** 세무서에 다시 가야 합니다. 그래서 이 도구는 인증이 한 번이라도 거절되면 `logs/card_fail.lock` 을 만들고 그 자리에서 전부 멈춥니다. 사람이 홈택스에서 카드 상태를 확인하고 그 파일을 지워야 다시 돕니다. 이 장치를 빼지 마세요.

**로그인도 한 번 실패하면 멈춥니다.** 계정이 잠기면 그날 일이 끝납니다. 다시 시도하는 코드를 넣지 마세요.

**세금계산서는 발행하면 되돌리기 어렵습니다.** 취소하려면 수정세금계산서를 또 발행해야 하고, 상대에게 메일이 두 번 갑니다. 처음 시험할 때는 반드시 본인 소유의 다른 사업자에게 1,000원 같은 소액으로 하세요.

**자격 파일은 윈도우 `%USERPROFILE%\.hometax\credentials.json`, 맥 `~/.hometax/credentials.json` 에 있습니다.** 거래처 장부(`partners.json`)와 읽어 둔 사진 건(`draft.json`)도 같은 폴더에 있습니다. 본인 계정만 열 수 있게 권한을 잠그지만, 이 PC가 뚫리면 카드도 같이 뚫립니다. 그 파일을 다른 곳에 복사하거나 메신저로 보내지 마세요. 이 저장소에는 올라가지 않습니다.

## 화면 구조에서 걸리기 쉬운 곳

주소를 직접 치고 들어가면 메인으로 튕깁니다. 사람처럼 메뉴를 눌러야 합니다. 그 메뉴가 코드로는 안 열릴 때가 있는데, 그때는 홈택스 검색창에 메뉴 이름을 치고 결과 줄을 누르는 길이 확실합니다.

인증 선택과 보안카드 입력은 같은 화면의 겹창이 아니라 **따로 뜨는 창**입니다. 이걸 모르면 코드가 엉뚱한 창을 붙잡고 헤맵니다.

로그인은 30분 아무 동작이 없으면 끊깁니다. 발행 직전에 로그인하는 흐름으로 쓰세요.

발급은 아이디 로그인으로 되지만 조회와 수정발급은 잠깁니다. 그때도 인증 창이 따로 뜨니 보안카드로 통과하면 풀립니다.
